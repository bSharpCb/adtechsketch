intentionally minimalist app for creating flowcharts. built on a tldraw fork.

some high level bulleted features:
- freehand drawing
- shape recognition/replacement (draw a sloppy square, auto-replaced with a neat one)
- stamps for various tools within the adtech ecosystem
- permutive sits in the middle because it is great (and i work there)
- twitter is called twitter and will not be named with one letter. i do not care.


some hotkeys:
- A: arrow
- V: select
- P: pen
- T: text


*secret hotkeys* aka tldraw features that aren't displayed in the toolbar
- while object selected, shift+D: duplicate selected object (must click to duplicate)
- F: creates a frame (put stamps in the frame, then move the frame around to move as group)
- O: circle
- R: rectangle
- L: line (click/drag)
